# Wallpapers

Drop your wallpaper here as `default.jpg`.

Hyprland config references `$HOME/Pictures/wallpapers/default.jpg` — so once you put a file with that name (or symlink) at that location, `hyprpaper` will pick it up on `hyprctl reload`.

Supported formats: jpg, png, webp.

For 4K wallpapers, use jpg (smaller, faster load).
